Razer SensorFinder

Razer Huntsman 아날로그(광학) 키보드에서 실제로 눌림이 감지되는 키와 깊이를 실시간으로 보여주고, 키별 입력 지점(윈도우 키 포함)을 직접 설정합니다.

이 브라우저는 WebHID를 지원하지 않습니다. 데스크톱 Chrome 또는 Edge로 여세요.
연결 안 됨 리포트 0

키 깊이 맵

입력/해제 지점 아직 불러오지 않음 — 불러오면 입력이 실제로 됐는지 판정합니다

감지 중(입력 지점 전) 입력 중 · 테두리: 주황 = 감지만 되고 입력된 적 없음(미세 접촉), 초록 = 입력된 적 있음 · 숫자 = 감지 횟수 · 감지된 키 안의 실선 = 입력 지점, 점선 = 해제 지점. 키를 클릭하면 아래 그래프에 표시됩니다.

연결은 됐지만 깊이 데이터가 들어오지 않습니다. 깊이 스트림은 키보드가 드라이버 모드일 때만 나옵니다. Razer Synapse를 실행해 둔 상태(트레이 포함)에서 키를 눌러 보세요.

키 깊이 그래프 (최근 5초)

키를 누르거나 맵에서 키를 클릭하세요.

입력/해제 판정은 불러온 입력·해제 지점으로 계산한 추정입니다. Rapid Trigger는 반영하지 않습니다.

감지된 키 순위

여유 = 입력 지점 − 최대 깊이. 여유가 남아 있으면 그 키는 한 번도 입력 지점까지 눌리지 않은 것입니다.

키별 입력 지점 읽기 / 설정

      
Synapse가 조절 대상에서 빼놓은 키(윈도우 키 등)도 펌웨어 명령 02:92 / 02:12로 직접 읽고 쓸 수 있습니다.

      

        먼저 Synapse를 완전히 종료하세요 (트레이 아이콘 → 종료). Synapse가 실행 중이면 키보드는 드라이버 모드이고, 입력 판정을 Synapse가 PC에서 직접 하므로 키보드에 적은 값이 무시됩니다.
        Synapse가 시작하거나 종료되며 모드를 바꾸면 프로필 0(RAM) 값은 활성 프로필 값으로 덮어써집니다.
      

      

        
        
        
      

      

      

        
        
        
        
      

      

        입력 지점: 값이 클수록 더 깊이 눌러야 입력됩니다 (V3 계열 0.1–4.0 mm, V2 계열 1.5–3.6 mm).

        해제 지점: 키가 이 깊이보다 위로 올라와야 떼어진 것으로 처리됩니다. 입력 지점보다 0.1 mm 이상 얕아야 하고, 0.1–0.2 mm 차이가 일반적입니다. 차이가 너무 작으면 경계에서 입력이 떨릴 수 있습니다. 비워 두면 기존 값을 유지합니다.
      

      

    

  


  
비공식 도구입니다. 프로토콜은 공개된 리버스 엔지니어링 자료(easyrazer, AnalogSense, razer-analog-linux)를 바탕으로 합니다. 사용에 따른 책임은 사용자에게 있습니다.
